# SuperShell

[![Release](https://img.shields.io/github/v/release/SuperFedora/supershell?label=SuperShell)](https://github.com/SuperFedora/supershell/releases)
[![License: Apache 2.0](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](LICENSE)

Native Rust 16-bit desktop shell workspace (`superdock`, `superbar`, `supersettings`, `superlock`) and layer-shell components for **[SuperFedora](https://superfedora.github.io/)**. Notifications & 16-bit Cast Comms live in **[supernotify](https://github.com/SuperFedora/supernotify)**.

```bash
superdock [status|position|autohide|pin|unpin|layout|tui]
superbar [status|toggle|deck|icons|clock|tui]
supersettings [tui|probe|apply|open|toggle]
superlock [lock|status|list|next|set|switch|idle|tui]
```

* **Binaries:** Installed to `~/.local/bin/{superdock,superbar,supersettings,superlock}`.

**Full documentation & keybinding reference: [superfedora.github.io](https://superfedora.github.io/)**
